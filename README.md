# 🐍 Bot de Vagas de Estágio em Python

Projeto desenvolvido em Python para automação de busca, coleta e organização de vagas de estágio.

---

## 📌 Sobre o Projeto

O objetivo principal deste projeto é automatizar o monitoramento de oportunidades de estágio, aplicando conceitos essenciais de desenvolvimento em Python, como:
- **Requisições HTTP** para consumo de serviços/APIs.
- **Estruturação Modular** para separação de responsabilidades.
- **Manipulação de Arquivos** para persistência dos dados coletados.
